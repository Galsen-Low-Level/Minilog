nodes.reference | None sphinx.ext.intersphinx._resolve.resolve_reference_detect_inventory ( BuildEnvironment  env,
pending_xref  node,
TextElement   contnode 
) 
Attempt to resolve a missing reference via intersphinx references.

Resolution is tried first with the target as is in any inventory.
If this does not succeed, then the target is split by the first ``:``,
to form ``inv_name:new_target``. If ``inv_name`` is a named inventory, then resolution
is tried in that inventory with the new target.
