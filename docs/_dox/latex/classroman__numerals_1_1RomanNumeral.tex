\doxysubsection{Detailed Description}
\begin{DoxyVerb}A Roman numeral.

Only values between 1 and 3,999 are valid.
Stores the value internally as an ``int``.

>>> answer = RomanNumeral(42)
>>> print(answer.to_uppercase())
XLII
