\hypertarget{md__2home_2umar_2Desktop_2WorkShop_2GLL_2Minilog_2README_autotoc_md32}{}\doxysubsection{\texorpdfstring{About}{About}}\label{md__2home_2umar_2Desktop_2WorkShop_2GLL_2Minilog_2README_autotoc_md32}
As its name suggests, {\bfseries{minilog}} is a tool dedicated to native logging based on termcapabilities . It adapts automatically to different terminals, thanks to its {\bfseries{support for termcapabilities}}, and is often already present on most Unix systems.

Lightweight and easy to use, it has no external dependencies, which {\itshape {\bfseries{reduces the memory footprint}}} when used.

By default, for fast display, standard output is not buffered, i.\+e. it is not timed. by the operating system, giving you instant display of messages. It can be quickly integrated into your workflow, as the project is built into a single file called a {\itshape shared object}.

It can be integrated into your code by creating a link to it.

\begin{quote}
\mbox{[}!\+IMPORTANT\mbox{]} For the moment, python support is under construction, and will be offered as a package using this shared object file.

\end{quote}
