\doxysubsection{Detailed Description}
\begin{DoxyVerb}Gather bibliography entries to tail of document.

Before::

    <document>
        <paragraph>
            blah blah blah
        <citation>
            ...
        <paragraph>
            blah blah blah
        <citation>
            ...
        ...

After::

    <document>
        <paragraph>
            blah blah blah
        <paragraph>
            blah blah blah
        ...
        <thebibliography>
            <citation>
                ...
            <citation>
                ...
\end{DoxyVerb}
