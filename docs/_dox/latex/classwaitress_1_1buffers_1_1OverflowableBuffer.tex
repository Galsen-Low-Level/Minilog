\doxysubsection{Detailed Description}
\begin{DoxyVerb}This buffer implementation has four stages:
- No data
- Bytes-based buffer
- BytesIO-based buffer
- Temporary file storage
The first two stages are fastest for simple transfers.
\end{DoxyVerb}
