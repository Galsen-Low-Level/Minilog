\doxysubsection{Detailed Description}
\begin{DoxyVerb}Transform specific admonitions, like this:

    <note>
        <paragraph>
             Note contents ...

into generic admonitions, like this::

    <admonition classes="note">
        <title>
            Note
        <paragraph>
            Note contents ...

The admonition title is localized.
\end{DoxyVerb}
