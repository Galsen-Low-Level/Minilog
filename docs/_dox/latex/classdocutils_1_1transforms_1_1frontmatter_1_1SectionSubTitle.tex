\doxysubsection{Detailed Description}
\begin{DoxyVerb}This works like document subtitles, but for sections.  For example, ::

    <section>
        <title>
            Title
        <section>
            <title>
                Subtitle
            ...

is transformed into ::

    <section>
        <title>
            Title
        <subtitle>
            Subtitle
        ...

For details refer to the docstring of DocTitle.
\end{DoxyVerb}
